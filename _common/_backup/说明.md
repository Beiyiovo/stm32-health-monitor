# 501 心率算法备份说明

## max30102_用峰计心率版_20261007.c

**这个版本的状态：**
- 心率：75~115（★ 系统性偏高约 15~20%，真实应 60~75）
- 血氧：93~98（正常）
- 采样率：25.0 样本/秒（正确）
- FIFO 从不溢出，I2C 零失败

**算法要点：**
- 一阶高通（减 DC，>>4 跟踪）+ 二阶高通（去基线漂移，>>5）
- 峰值检测状态机：case0 找峰 → case1 找谷
- 心率 = 25 x 60 / 峰值间隔中位数
- 四层重搏波防护：不应期6 + 高度门槛26% + 倍数修正 + 整体加倍(med<14)
- 血氧：Maxim 官方二次拟合公式 + 5:1 平滑
- 预热期：心率 4 秒 / 血氧 6 秒

**问题：**
峰值检测会把一部分【重搏波】当成心搏，导致间隔偏小、心率偏高。
（重搏波幅度约主峰的 20~40%，高度门槛挡不干净）

**为什么保留这个版本：**
心率虽然偏高 15~20%，但趋势正确、重复性好，是可以交付的保底方案。
如果新方案调试不顺利，可以随时切换回来。
